# Версионирование Laveyana — v.YY.MM.vv

Для сборок Laveyana.Maui.UI используется четырёхкомпонентный формат:

`v.YY.MM.vv`

| Компонент | Значение |
|---|---|
| `v` | Глобальная версия библиотеки (0 — предварительная разработка, 1 — первая стабильная версия; далее увеличивается при осознанном глобальном выпуске) |
| `YY` | Последние две цифры года выпуска (например, `26`) |
| `MM` | Месяц выпуска, обязательно две цифры от `01` до `12` |
| `vv` | Порядковый номер опубликованного выпуска в данном месяце, начиная с `1`, без ведущих нулей |

Примеры: `0.26.11.1` (первый предварительный выпуск ноября 2026), `0.26.11.2` (следующий выпуск ноября), `0.26.12.1` (первый выпуск декабря), `1.27.01.1` (стабильная серия, январь 2027).

Версию **не повышать на каждый коммит или CI-прогон**. Новый `vv` выделяется при подготовке очередного релиза. При смене календарного месяца `vv` сбрасывается на `1`. `v` меняется отдельно в соответствии с жизненным циклом библиотеки. Для `Laveyana.Maui.UI` и `Laveyana.Maui.UI.Windows` используется **одна и та же версия** из корневого `Directory.Build.props`.

## GitHub и NuGet

- В исходниках: `<LaveyanaVersion>0.26.11.1</LaveyanaVersion>`.
- Git-тег и GitHub Release: **`v0.26.11.1`** (символ `v` только как префикс тега; в имени пакета его нет).
- Нормальная версия NuGet: **`0.26.11.1`**.
- NuGet официально поддерживает четыре числовых компонента, но **нормализует ведущие нули**. Поэтому Git-тег `v1.27.01.1` соответствует версии пакета `1.27.1.1`; это не ошибка. Проверка и публикация выполняют нормализацию.
- Внимание: это **не SemVer**, и NuGet не может по сегментам `YY.MM.vv` делать обычные предположения о совместимости API. До глобальной версии 1 совместимость не гарантируется.
- Внимание: числовая версия `0.26.11.1` **не становится prerelease-пакетом NuGet** автоматически. При выпуске с глобальной версией 0 GitHub Release должен быть отмечен как Pre-release, однако для NuGet потребуется отдельное решение о суффиксах предварительной версии, если важна именно prerelease-классификация NuGet. В текущем строгом формате суффиксов нет.

Проверка структуры версии без SDK: `python tools/check_version.py`. Проверка Git-тега: `python tools/check_version.py --tag v0.26.11.1`. Тесты правил: `python -m unittest discover -s tools -p test_versioning.py`.

Документация Microsoft: https://learn.microsoft.com/en-us/nuget/concepts/package-versioning
