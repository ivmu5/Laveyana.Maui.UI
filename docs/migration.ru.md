# Интеграция приложений

1. Добавить PackageReference на Laveyana.Maui.UI; Windows-пакет подключать только для Windows TFM.
2. Использовать UiThemeManager либо локальные ResourceDictionary с его ключами; преобразовывать только параметры интерфейса, не меняя формат предметных настроек.
3. Перенести общие кнопки, текст, карточки, числовой ввод и палитры на Ui и UiDesignTokens.
4. Проверить жесты, навигацию, доступность, DPI, темы и восстановление настроек.
5. Виртуализация UiVirtualList рассчитана на постоянную высоту строк. Не заменять специализированные списки без тестов.
6. Заголовок Windows подключать после проверки F11, drag regions и восстановления размеров; не создавать два заголовка одновременно.

## Обновление до 0.26.11.2

Стандартный preset теперь UiPalettePreset.Laveyana, дополнительная зелёно-голубая палитра — UiPalettePreset.Mint. Старые имена enum удалены: это намеренное изменение исходного API. Значения enum 0–4 и RGB не изменены, поэтому числовые Preferences совместимы. Приложения, сериализующие enum строками, должны преобразовать прежние имена на своей стороне. Обновите ссылку на соответствующий preset и версию пакета вместе.

Не меняйте ApplicationId, ключи Preferences и путь данных при миграции. Платформенный код с разрешениями и предметные модели остаются в потребителях.
